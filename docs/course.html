Multimodal Data Analysis with Claude

Duration
8 weeks
Modules
11
Pace
1-2 hrs/day

An 11-module, self-paced course on analyzing text, images, PDFs, audio, tabular files and logs with Claude, using a local MongoDB as the workbench. About 8 weeks at 1–2 hours a day, plus a capstone.

Prerequisites

  • Docker – All development happens in containers
  • Git – For version control
  • GitHub account – To fork the repository
  • Anthropic API key – $10–20 covers Modules 0–4

How to Follow

  • Fork first. Make your own copy of the repo on GitHub
  • Do modules in order. Each step builds on previous ones
  • One shared library. All functions go in lib_claude_multimodal.py
  • Each module has a check. Prove your work at the end of each module

Start of Every Session

cd DataAnalysis_with_LLM
docker compose up -d
until docker compose ps mongodb | grep -q "(healthy)"; do sleep 3; done
echo "MongoDB ready"

Learning Outcomes

  1. Call Claude with tools, streaming, and error handling. Track every call's cost.
  2. Turn six input types into structured, validated data.
  3. Build evaluation sets and measure accuracy with evidence.
  4. Decide which tasks can run unattended based on error rates.
  5. Let Claude answer by writing SQL without inventing numbers.
  6. Combine formats with full-text search and citations.
  7. Guard against prompt injection with least-privilege users.
  8. Package for production with secrets, logging, and CI gates.

Module 1: Claude API Fundamentals

Duration
2–3 days
Builds on
Module 0

You finish with: ask(), log_call(), tool loop, and cost tracking in your shared library.

Key Ideas

  • Streaming: See words as they arrive, not all at once
  • Tools: Claude calls functions, you handle results, loop until done
  • Cost tracking: Log tokens and calculate per-call cost
  • One library: Every module imports from lib_claude_multimodal.py

Before You Start

cd DataAnalysis_with_LLM
docker compose up -d
until docker compose ps mongodb | grep -q "(healthy)"; do sleep 3; done; echo "MongoDB ready"
1
Create the Shared Library

Create lib_claude_multimodal.py at the project root with the core ask() function:

"""Shared helpers for the Multimodal Data Analysis with Claude course."""
import anthropic
import json
import os
from datetime import datetime
from pymongo import MongoClient

# Initialize clients
client = anthropic.Anthropic(api_key=os.environ.get("ANTHROPIC_API_KEY"))
db_rw = MongoClient(os.environ.get("MONGODB_URI_RW")).course
db_ro = MongoClient(os.environ.get("MONGODB_URI")).course

# Cost per million tokens (as of knowledge cutoff)
COST_PER_MTK_INPUT = 0.80
COST_PER_MTK_OUTPUT = 2.40

def log_call(model, messages, response, tools=None):
    """Log API call to MongoDB."""
    cost_input = (response.usage.input_tokens / 1_000_000) * COST_PER_MTK_INPUT
    cost_output = (response.usage.output_tokens / 1_000_000) * COST_PER_MTK_OUTPUT
    cost_total = cost_input + cost_output

    call_doc = {
        "timestamp": datetime.utcnow(),
        "model": model,
        "input_tokens": response.usage.input_tokens,
        "output_tokens": response.usage.output_tokens,
        "cost_input": cost_input,
        "cost_output": cost_output,
        "cost_total": cost_total,
        "messages_count": len(messages),
    }

    if tools:
        call_doc["tools_count"] = len(tools)

    db_rw.llm_calls.insert_one(call_doc)
    return cost_total

def ask(prompt, model="claude-haiku-4-5-20251001", system=None, tools=None, max_tokens=512):
    """Call Claude and log the cost."""
    messages = [{"role": "user", "content": prompt}]

    kwargs = {
        "model": model,
        "max_tokens": max_tokens,
        "messages": messages,
    }

    if system:
        kwargs["system"] = system

    if tools:
        kwargs["tools"] = tools

    response = client.messages.create(**kwargs)

    log_call(model, messages, response, tools)

    # Return just the text content
    return response.content[0].text

def cost_of(input_tokens, output_tokens):
    """Calculate cost of a call."""
    cost_input = (input_tokens / 1_000_000) * COST_PER_MTK_INPUT
    cost_output = (output_tokens / 1_000_000) * COST_PER_MTK_OUTPUT
    return cost_input + cost_output
Check: Run python -c "from lib_claude_multimodal import ask; print('ok')"
2
Create Your First Script

Create m01_chat.py:

#!/usr/bin/env python3
"""Simple chat with Claude that logs cost."""
from lib_claude_multimodal import ask, db_ro

print("Chat with Claude. Type 'quit' to stop.\n")

while True:
    prompt = input("You: ").strip()
    if prompt.lower() == 'quit':
        break

    if not prompt:
        continue

    response = ask(prompt)
    print(f"Claude: {response}\n")

# Show costs
calls = list(db_ro.llm_calls.find({}))
total_cost = sum(c['cost_total'] for c in calls)
print(f"\nTotal calls: {len(calls)}")
print(f"Total cost: ${total_cost:.4f}")
