Data Analysis with LLM — Complete Course

Welcome

This comprehensive course teaches you how to build practical applications that combine Claude's API with multimodal data analysis. You'll learn to process text, images, PDFs, audio, video, databases, and logs—all in one integrated system.

What You'll Learn

  • Set up a complete environment with Docker, MongoDB, and Claude API
  • Master Claude API fundamentals, tool use, and cost tracking
  • Build text classification pipelines with evaluation metrics
  • Extract data from images, charts, PDFs, and documents
  • Transcribe and analyze audio and video
  • Query tabular data with SQL through Claude
  • Parse logs and semi-structured text
  • Aggregate data across MongoDB collections
  • Build document search and retrieval systems
  • Deploy to production with security and evaluation gates

Course Structure

11 modules over 3-4 weeks. Each module builds on the previous one, with working code at every step.

Module 0 — Setup (1 day)

Start: A machine and an API key. Finish: MongoDB running, Python ready, API access verified.

What This Lab Is About

Set up your complete development environment with Docker, MongoDB, and Claude API. Every step verifies itself before moving to the next.

Key Ideas

  • Docker is standard. Every machine sees the same environment.
  • Secrets stay out of git. `.env` is never committed. Passwords and API keys go there.
  • Least privilege. Database has two users: admin (setup only) and course (read/write, used in scripts).

Quick Start

1. Copy .env and add your secrets:

cp .env.example .env
# Edit .env: set ANTHROPIC_API_KEY and MONGO_ROOT_PASSWORD

2. Start MongoDB:

docker compose up -d
until docker compose ps mongodb | grep -q "(healthy)"; do sleep 3; done

3. Test connections:

python -c "from pymongo import MongoClient; import os; from dotenv import load_dotenv; load_dotenv(); MongoClient(os.environ['MONGODB_URI_RW']).admin.command('ping'); print('MongoDB OK')"

4. Create shared library:

cat > lib_claude_multimodal.py << 'EOF'
"""Shared helpers for the Multimodal Data Analysis with Claude course."""
import os, time
from datetime import datetime, timezone
import anthropic
from dotenv import load_dotenv
from pymongo import MongoClient
load_dotenv()
HAIKU = "claude-haiku-4-5-20251001"
PRICES = {HAIKU: (1.00, 5.00)}
client = anthropic.Anthropic(max_retries=4, timeout=120.0)
db_rw = MongoClient(os.environ["MONGODB_URI_RW"]).course
db_ro = MongoClient(os.environ["MONGODB_URI"]).course
EOF

Done When

Setup Checklist

  • MongoDB shows (healthy)
  • Claude API call returns a response
  • `.env` is git-ignored
  • `lib_claude_multimodal.py` has database clients

Module 1 — Claude API Fundamentals (2-3 days)

Finish with: `ask()` function, cost tracking, tool use, calculator.

What This Lab Is About

Build the `ask()` function that logs every API call. Add tool support so Claude can ask for calculations. Create a simple chat interface.

Key Idea

One function to rule them all: Every Claude call goes through `ask()`, which logs cost, tokens, and latency to MongoDB.

Module 2 — Text Analysis (1 week)

What This Lab Is About

Classify reviews. Compare prompt versions. Measure accuracy on test data. See which prompts work best.

Module 3 — Images (4-5 days)

What This Lab Is About
